# 🪢 Kötélhúzó Kvíz – 8. Osztályos Műveltségi Bajnokság

Egyetlen önálló HTML fájlból álló, interaktív kötélhúzó vetélkedőjáték 8. osztályos diákok számára (5–8. osztályos tananyag alapján).

## 🎮 Főbb jellemzők
- **200 kérdéses tananyagbázis**:
  - 📖 **Irodalom**: 60 kérdés
  - ✍️ **Magyar nyelvtan**: 60 kérdés
  - 🇭🇺 **Magyar témakörök összesen**: 120 kérdés (60%)
  - 🌐 **Egyéb tantárgyak összesen**: 80 kérdés (40%)
    - 🏰 Történelem: 13 kérdés
    - 📐 Matematika: 12 kérdés
    - 🔬 Biológia: 10 kérdés
    - 🌍 Földrajz: 10 kérdés
    - ⚡ Fizika: 10 kérdés
    - 🧪 Kémia: 10 kérdés
    - 🎵 Ének-zene: 8 kérdés
    - 🌿 Természettudomány: 6 kérdés
    - 🌱 Környezetvédelem: 1 kérdés
- **Egyéni párbaj (1 vs 1)**: Kék versenyző vs. Piros versenyző a kötélen, dinamikus húzó animációval és valós idejű kötélmozgással.
- **Gyors tantárgyi profilok a Beállításokban**:
  - ⚔️ *Összes tantárgy (200 kérdés)*
  - 📚 *Csak Magyar (120 kérdés: 60 irodalom + 60 nyelvtan)*
  - 🔬 *Reál + Történelem (80 kérdés)*
  - Egyedi tantárgyválasztási lehetőség jelölőnégyzetekkel
- **Beépített szintetizált hangok**: Web Audio API (nincs külső audiófüggőség).
- **Kényelmes vezérlés**:
  - 🔵 **Kék versenyző**: `A`, `S`, `D`, `F` vagy `1`, `2`, `3`, `4`
  - 🔴 **Piros versenyző**: `H`, `J`, `K`, `L` vagy `7`, `8`, `9`, `0`
  - 🔊 **Hang némítása/visszakapcsolása**: `M` billentyű
- **100% Offline és önálló**: Nincs szükség szerverre, az `index.html` önmagában fut bármilyen okostáblán, projektoron vagy számítógépen.

## 🚀 Indítás
Kattints duplán az `index.html` fájlra a megnyitáshoz bármely modern böngészőben (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari).
